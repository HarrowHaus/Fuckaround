# DEATHCORE PRODUCTION — full instrumental pipeline

An end-to-end, headless deathcore production system: research-driven composition,
multi-mic sampled drums (DrumGizmo), SFZ guitars with real articulations through a
neural amp sim + cabinet IRs, and a code-driven mix/master chain targeting modern
deathcore loudness.

**Status: build in progress.**

- `docs/` — research reports (2026 deathcore landscape, composition, mixing, tooling)
- `src/` — composition engine, render pipeline, mix/master chain
- `midi/` — generated MIDI (drums, guitars, bass, orchestration)
- `mix/` — final master (WAV/MP3)
- `samples/`, `tools/`, `stems/` — gitignored (downloaded kits, built renderers, intermediate audio)
